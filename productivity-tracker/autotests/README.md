# Автотесты — Productivity Tracker

Playwright (JavaScript): 40 API-тестов и 7 UI-тестов.

## Как устроены

- `tests/api/auth.spec.js` — регистрация, вход, токен
- `tests/api/activities.spec.js` — активности и цели: валидация, граничные значения, права доступа, ответы при ошибках
- `tests/ui/ui.spec.js` — регистрация через форму, редирект без входа, цели, «Анализ дня»
- `tests/helpers.js` — создание тестового пользователя через API

Каждый тест создаёт себе нового пользователя с уникальным email, поэтому тесты не зависят друг от друга и от порядка запуска.

**Тесты на известные баги** помечены `test.fail('BUG-00X: ...')`. Они проверяют правильное поведение, сейчас падают из-за бага, и Playwright считает это ожидаемым результатом. Когда баг исправят, тест станет красным — это сигнал убрать пометку. Так набор остаётся зелёным, а баги не теряются.

## Запуск

Нужны запущенные backend (`http://localhost:3001`) и frontend (`http://localhost:3000`) проекта.

```bash
npm install
npx playwright install chromium
npm test            # все тесты
npm run test:api    # только API
npm run test:ui     # только UI
npm run report      # HTML-отчёт
```

Другие адреса можно передать так:
```bash
API_URL=http://localhost:3001/api UI_URL=http://localhost:3000 npm test
```
